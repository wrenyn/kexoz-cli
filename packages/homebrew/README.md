# Homebrew tap

The release workflow generates `Formula/kexoz.rb` from the six published binaries
and their verified `SHA256SUMS`, then opens a PR in `wrenyn/homebrew-tap`.
The formula is generated by `scripts/prepare-packages.mjs`; no handwritten
formula with placeholder checksums should be submitted to the tap.

Merge the PR, then run `brew install wrenyn/tap/kexoz` and `brew test kexoz`.
See `docs/RELEASING.md` for account and token setup.
